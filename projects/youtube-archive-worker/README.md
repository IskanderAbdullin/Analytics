# YouTube archive owner Worker

Dedicated Worker `youtube-archive-owner` at https://youtube-archive-owner.videns42.workers.dev/mcp. Only this new Worker and its own OAuth KV namespace may be changed by its deployment workflow. No other Workers, routes or bindings are modified. Source contains no owner IDs, Google credentials, captions or tokens.

Version 0.1 was deployed and verified via route diagnostic (health 200, discovery 200, no-auth call 401). Version 0.2 adds a standard MCP OAuth provider and Google upstream authorization. Before enabling owner login configure the three named secrets/variables on this Worker: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `YOUTUBE_OWNER_CHANNEL_ID`. Create a Google Cloud Web application OAuth client, enable YouTube Data API v3, register exact redirect URI `https://youtube-archive-owner.videns42.workers.dev/callback`, and add owner to OAuth testing audience if required. No secret in chat or Git. The Google scope `youtube.force-ssl` is required for reading captions; the Worker exposes only fixed GET data methods. Google token is held in encrypted OAuth grant props; downstream MCP tokens have their own audience, not Google token passthrough. Only ChatGPT CIMD client and verified callback host accepted. Only explicitly configured owned channel is served. OAuth testing mode may expire upstream refresh grants after seven days; verify real consent and refresh. Until then no private video transcript is claimed. Existing public text archive and control state remain in private project repository.
