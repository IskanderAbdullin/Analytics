# Машиночитаемые контракты — draft v1

Эти JSON Schema задают первую версию обмена данными. Они являются **проектными контрактами**, не доказательством реализации кода.

- `bot-event.schema.json`: контракт строки JSONL от OsEngine/робота. Все времена UTC; decimal-числа кодируются строками. События должны иметь стабильные event ID и provenance; недоступный broker_order_id допустим и впоследствии связывается reconciliation.
- `pnl-report.schema.json`: структура отчёта с policy hash, data snapshot, качеством и деталями источников. Денежные компоненты в отдельных валютах (не суммировать напрямую).

**Совместимость:** новые необязательные поля допускаются в `bot-event/v1`, но изменения смысла обязательных полей требуют версии `v2`. `pnl-report/v1` пока строгий для уменьшения риска молчаливых несовпадений потребителей.

**Безопасность:** `account_ref` — псевдоним, не номер счёта; в fixtures нельзя включать tokens/client secrets/PII. Использовать JSON Schema валидатор в CI, а формат decimal конвертировать в точную Decimal/C# decimal.
