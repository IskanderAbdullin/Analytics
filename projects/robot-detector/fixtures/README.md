# Синтетические тестовые данные

Здесь **нет реальных рыночных данных и персональных сведений**.

- `synthetic_twap_5s.csv` — шесть печатей по 100 лотов с шагом около 5 секунд, отсутствует цикл 15 сек, и один шумовой print 40 лотов.
- `synthetic_twap_5s_expected.json` — ожидаемая проверочная гипотеза, включая список конкретных событий и отсутствие калиброванной вероятности.

Фикстура иллюстрирует **проверку** одной гипотезы; поиск периода/фазы без подсказки — отдельное требование этапа 1. Допуски времени и объемов настраиваются. Не интерпретировать как шесть заявок одного конкретного трейдера.

### Новый QV-пример (18.11.2026)

- [synthetic_quote_oscillation.csv](synthetic_quote_oscillation.csv) — 5 **искусственных** снимков top-of-book за 400мс, ask oscillates 101.00→101.01→101.00→101.01→101.00, bid не изменяется, **сделок нет**.
- [synthetic_quote_oscillation_expected.json](synthetic_quote_oscillation_expected.json) — `CarryAsk=0.04`, `BigAsk=0`, `OscAsk=4.0` при `price_step=0.01`, `OscBid=0`. Наличие осцилляций не доказывает самостоятельного робота и не даёт калиброванной вероятности.
- В реальности для такого окна потребуется частая непрерывная L2 выборка. При 100ms throttling события быстрее интервала могут потеряться; synthetic fixture не подтверждает достижимость такого покрытия у T-Invest.
