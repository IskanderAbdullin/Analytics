## Результат, включая неприятный для гипотезы

| Когорта | Событий публичных сделок | L2 snapshots | Доля исполнений у сетки 45с, среднее по 3 seeds | Legacy 10s alarms |
|---|---:|---:|---:|---:|
| Poisson noise, без target | **3 428** | 5 855 | **0,01022026** | 0 из 3 |
| Fixed-20s noise, **без target** | **2 853** | 4 789 | **0,08201092** | **3 ложных тревоги из 3** |
| Momentum noise, без target | **2 805** | 4 668 | **0,00990425** | 0 из 3 |
| Poisson noise + injected TWAP (45с) | **3 482** | 6 363 | **0,03022026** | **0 из 3 — 3 пропуска** |

Суммарно **12 568 публичных исполнений** и **21 675** снимков L2 из 12 genuine original simulations. Posthoc oracle подтвердил **67 исполнений с участием контролируемого TWAP** за три positive runs (22, 24, 21 соответственно).

**Суть отрицательного результата:** в фоновой fixed-20s когорте **без** injected TWAP доля совпадений с 45-секундной сеткой **больше**, чем в позитивной когорте. Нельзя объявить найденную временную частоту уникальной «подписью TWAP». Положительный сигнал на одной фиксированной фазе по-прежнему может быть просто гармоникой чужого регулярного потока.

Прежний 10-секундный детектор по заранее зафиксированному порогу 0,22 вновь ошибся **3/3** на fixed-cadence фоне и пропустил **3/3** позитивных случаев. Это не повод подбирать красивый порог после просмотра данных. Вспомогательные сетки **10/20/45/90 секунд** заранее зафиксированы и дают лишь описательные частоты и lifts, не p-values.

## Что сделано по L2

- Поведение public-only quote book исследовано на **5 уровнях** каждой стороны; источник настоящие simulated matching-engine L2 snapshots.
- Для временных окон **30/60 секунд** рассчитаны лагированные признаки, используя **только предыдущий завершённый bin**. Нулевая ликвидность, неполный стакан и stale snapshots приводят к reason-coded abstention.
- Исходных eligible 30s bins в отдельных случаях **9–15**, для 60s — **4–7**. Поэтому корреляция по нескольким 60s интервалам может быть вообще не определена; нельзя изображать её устойчивой оценкой.
- Суммарные abstained trade bins: Poisson **5/3** (30/60), fixed cadence **13/8**, momentum **13/7**, TWAP **7/3**. Это счётчики окон, **не market-FDR**.
- Ни одно значение \`agent_id\`, trader/broker ID или внутриалгоритмический oracle label **не входило в** public-only feature pipeline; скрытое подтверждение контролируемого TWAP вычислялось **после** public-only inference.
- Отсутствует независимый сертификат полноты L2 и известная настоящая частота physical-owner bots.

## Что эти данные НЕ доказывают

Это **моделирование** в ABIDES-NG, а не биржевые котировки настоящих владельцев и не independent holdout за пределами проекта. Здесь 3 seeds на когорту; нельзя делать p-values без дополнительного статистического дизайна или выдавать реальные precision/recall/FDR. Наблюдаемая гетерогенность показывает проблему специфичности календарных ритмов и подтверждает необходимость более строгого conditioning on background.

Архивного реального source tape нет в репозитории; GitHub artifact ID **14719426242** содержит только компактные агрегаты, 7-дневный срок. Подробные исходные значения по 12 seed×cohort сохранены в [fixtures/abides_multiscale_public_l2_observed_20261121.json](../fixtures/abides_multiscale_public_l2_observed_20261121.json) без индивидуальных событий. После успешного оригинального прогона workflow отключён от auto-push, остаётся manual-only.
