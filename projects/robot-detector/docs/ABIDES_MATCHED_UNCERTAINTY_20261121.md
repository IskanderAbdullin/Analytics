# RD-MATCHED-UNCERTAINTY-14 — точный аудит малой выборки и парного сравнения

## Исходные данные и научное ограничение

Сохранены *те же самые* **16 оригинальных genuine ABIDES matching-engine сессий**,
по одной на каждую комбинацию 4 seeds (3201–3204)
и 4 заранее замороженных сценариев из
[эксперимента #44938991772](https://github.com/IskanderAbdullin/Analytics/actions/runs/44938991772).
**Новых исходных сессий для этого аудита не выполнялось.**
Сами исполнения и снимки L2 не являются независимыми
наблюдениями для доверительных интервалов.

[Протокол ретроспективного аудита](../research/abides_matched_uncertainty_audit_protocol_20261121.json)
явно утверждает, что все результаты 3201–3204
были просмотрены **до** назначения
конкретного статистического аудита.
Поэтому это не новая независимая валидация
и не подтверждение заранее известной
точности на реальных владельцах.

Численный модуль
[abides_matched_smalln_audit.py](../tools/abides_matched_smalln_audit.py)
проверяет все 16 первоначальных агрегатов,
их cohort counts, контроль отсутствия
raw trades и oracle agent IDs, различает
пары и вычисляет *двусторонние точные
интервалы Клоппера–Пирсона уровня 95%*
для **четырёх source-seed trials внутри
одного frozen synthetic cohort**.
Теоретическая интерпретация требует IID
Bernoulli trials. Выбор фиксированных
псевдослучайных seeds не удостоверяет
такое независимое распределение. Это
условные математические интервалы,
**не реальная рыночная FDR**.

## Показатели и пределы неопределённости

| Сценарий | Положительные сигналы per-print | Exact nominal 95% CP | Положительные сигналы grouped | Exact nominal 95% CP |
|---|---:|---:|---:|---:|
| Poisson без TWAP | **1/4** (ложный сигнал) | 0,0063–0,8059 | **1/4** (ложный сигнал) | 0,0063–0,8059 |
| Fixed 20s без TWAP | **0/4** | 0–0,6024 | **0/4** | 0–0,6024 |
| Momentum без TWAP | **0/4** | 0–0,6024 | **0/4** | 0–0,6024 |
| Injected TWAP 45s | **4/4** | 0,3976–1 | **3/4** | 0,1941–0,9937 |

Интервалы приведены лишь как *номинальные*
при условии повторных независимых
Bernoulli симуляций **того же** ABIDES
генератора/класса. **0/4 не доказывает
низкую долю ложных тревог**: даже при
идеальной Bernoulli интерпретации
двусторонняя верхняя граница около
**60%**. Аналогично **4/4** положительных
источников оставляют нижнюю границу
около **40%**. Не следует создавать
широкую «общую FDR 1/12»: все три
отрицательные когорты обладают
разными механизмами генерации и
не являются единым IID market cohort.

## Строго парный источник: сравнение без псевдорепликации

Оба метода вычислялись **на одних и тех
же 16 source tapes**, поэтому сравнительная
часть имеет 16 **пар**, не 32 независимых
сессии.

| Сценарий | Оба метода положительны | Только naive per-print | Только grouped | Оба отрицательны | Abstain |
|---|---:|---:|---:|---:|---:|
| Poisson | **1** | 0 | 0 | **3** | 0 |
| Fixed-20s | 0 | 0 | 0 | **4** | 0 |
| Momentum | 0 | 0 | 0 | **4** | 0 |
| Injected TWAP | **3** | **1** | **0** | 0 | 0 |

Единственный разошедшийся случай —
positive TWAP seed **3204**: naive обнаружил
целевой synthetic рисунок, группирование
пропустило. В Poisson seed **3203**
оба метода одинаково ошиблись;
следовательно, **никакого подтверждённого
выигрыша группирования нет**.
Ни McNemar significance, ни p-value
для реального рынка не вычисляются.

## Повышение мощности следующего genuine synthetic теста

Точный двусторонний верхний CP предел
для `0/n` при 95% равен
`1 − (0,025)^(1/n)`.
При **n=40** и без ошибок этот
математический предел равен примерно
**8,81%** для *одного и того же* синтетического
Bernoulli-сценария; даже это не рыночная FDR
и не гарантия отсутствия скрытого
изменения генератора. Нужно сохранять
**все** background false positives и
положительные misses, а не надеяться
на ноль.

Новый этап [RD-ABIDES-POWER-15, #96](https://github.com/IskanderAbdullin/Analytics/issues/96)
должен заранее заморозить **40 локально
неиспользованных seeds × 4 source cohorts**
и без постфактум изменения threshold
проверить оба фиксированных публичных
метода. Реальная научная цель #72
по-прежнему не закрыта.
