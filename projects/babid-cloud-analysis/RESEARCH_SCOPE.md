# Границы исследования

Аналитический проект полностью автономен. Разрешены чтение копий исходников
для понимания контрактов и формата, создание/редактирование кода **в Analytics**,
локальные синтетические тесты и GitHub Actions **Analytics**.

Необходимо соблюдать:
1. Не коммитить исходники торгового робота, его рабочие конфигурации и реальные торговые данные.
2. Не изменять Babid Cloud, Babid-C-gpt-, Claude или другие репозитории.
3. Не запускать торговую программу и не отправлять торговые команды.
4. Не управлять пользовательским компьютером без отдельного согласия.
5. Отчётность OsEngine Lab v2 вести в `Analytics/reports/osengine-lab/events/`.
6. Все гипотезы об ошибках и прибыльности подтверждать идентификаторами сделок,
   воспроизводимыми расчётами и явной оценкой качества источников.
7. Не подменять отсутствующие реальные данные синтетическими.
